# Database Schema

**PostgreSQL/PostGIS schema documentation for NexAlert**

## Overview

This directory contains schema documentation for the NexAlert backend database.

## Database Technology

- **Database**: PostgreSQL 15+
- **Extension**: PostGIS 3.3+
- **ORM**: SQLAlchemy 2.0

## Schema Documentation

Schema documentation files will be added in Phase 4+ (Canonical Telemetry Contract + Database).

## Business Schema

Business schema includes:
- Telemetry records and sensor assessments
- Hazard assessments and incidents
- Hazard geometries (PostGIS)
- Alerts and SOS requests
- Audit events
- Node and user management
